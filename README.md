# Sistema de Control de Inventario Automatizado - Hardware & Reco

## Descripción del Sistema
Este repositorio alberga la documentación técnica y el diseño del sistema de información automatizado para **Hardware & Reco**, una PyME dedicada a la venta de soluciones tecnológicas y al reacondicionamiento de hardware en desuso (incluyendo componentes de minería de criptomonedas) y armado de computadoras personalizadas.
El módulo desarrollado centraliza el control de stock en tiempo real entre la tienda física y la plataforma e-commerce, automatizando el cálculo de pérdidas/ganancias para el área de Finanzas, emitiendo alertas de stock bajo y garantizando tolerancia a fallos mediante servidores redundantes.

## Indicadores de Control y Estándares de Desempeño
Para la auditoría técnica y seguimiento de calidad del sistema, se establecen los siguientes indicadores clave:
* Sincronización de Precios y Stock: 0% de desfase de datos entre el local físico, el e-commerce y el sistema contable.
* Tiempo de Respuesta (Rendimiento): Consultas de disponibilidad en la tienda virtual menores a 1.5 segundos.
* Capacidad de Carga: Soporte de hasta 15,000 componentes registrados y 5,000 transacciones mensuales simultáneas.
* Disponibilidad: Infraestructura redundante (servidor principal y secundario) para garantizar un uptime del 99.9%.
